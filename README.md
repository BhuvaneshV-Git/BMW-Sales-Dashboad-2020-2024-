# BMW Sales Performance & Market Analysis

A comprehensive data analytics project focused on evaluating BMW vehicle sales performance from 2010 to 2024. This project leverages Microsoft Excel and Power BI to analyze sales trends, regional performance, vehicle characteristics, and model-wise comparisons to support data-driven business decisions.

## 📌 Project Overview

The BMW Sales Performance & Market Analysis project aims to extract meaningful insights from BMW sales data collected between 2010 and 2024. The analysis focuses on understanding sales behavior, identifying top-performing vehicle models, evaluating regional sales performance, and tracking market trends through interactive dashboards and business intelligence techniques.

## 📊 Dataset Information

This project uses a CSV dataset containing BMW vehicle and sales-related records.

## 🎯 Problem Statement

The project addresses the following business challenges:

- Analyze sales performance across regions and vehicle models.
- Identify top-performing and underperforming markets.
- Understand sales trends and consumer preferences.
- Compare vehicle models based on sales performance.
- Evaluate regional growth opportunities.
- Support strategic business decision-making through data insights.

## 🗂️ Dataset Attributes

| Attribute | Data Type | Description |
|------------|------------|-------------|
| Model | Text | BMW vehicle model name (X5, 3 Series, 5 Series, etc.) |
| Year | Integer | Manufacturing or sales year |
| Region | Text | Sales region or market |
| Colour | Text | Vehicle exterior color |
| Fuel Type | Text | Petrol, Diesel, Hybrid, or Electric |
| Transmission | Text | Manual or Automatic |
| Engine | Decimal | Engine capacity (Liters) |
| Mileage | Whole Number | Distance travelled (Kilometers) |
| Price | Currency | Vehicle selling price (USD) |
| Sales | Whole Number | Number of units sold |
